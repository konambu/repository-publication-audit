# Repository Publication Audit

Git リポジトリを公開する前に、ステージされたファイルからローカル専用データ・巨大ファイル・代表的な認証情報形式を検出する読み取り専用 CLI です。ゲーム開発環境をポートフォリオとして整理する際の監査処理を、独立したツールとして切り出しました。

## 特徴

- 作業ツリーではなく **Git インデックスの内容** を検査。ステージ後に書き換えたファイルも、コミットされる内容に基づいて判定します。
- Godot キャッシュ、Python キャッシュ、ログ、自動バックアップ、環境設定、参考モデル等の混入を検出します。
- 10 MiB 以上を警告、100 MiB 以上をエラーとして扱います。
- 秘密鍵のヘッダーや代表的なトークン形式を検出し、値を出力せずファイルパスと理由だけを JSON で返します。
- Python 標準ライブラリと Git のみを使用し、ファイル・インデックス・コミットを変更しません。

## 実行

Python 3.10 以降と Git が必要です。Git を PATH から実行できる環境で使用してください。

```sh
python tools/repository_audit.py /path/to/repository
python tools/repository_audit.py /path/to/repository --warnings-as-errors
python tools/repository_audit.py --help
```

引数を省略すると現在の作業ディレクトリが対象です。新しく公開するファイルを個別に `git add` した後に実行します。`git add .` や秘密情報の追加を推奨するものではありません。

| 終了コード | 意味 |
| --- | --- |
| 0 | 検出エラーなし。警告は JSON を確認 |
| 1 | 検出エラーあり。厳格モードでは警告も対象 |
| 2 | Git 実行失敗、競合、サブモジュール等により監査を実行できない |

## 検査範囲と制約

対象は指定リポジトリのインデックスです。未追加ファイル、過去のコミット履歴、GitHub の公開設定、権利関係、マルウェア、実行時の脆弱性は検査しません。

認証情報の内容検査は 2 MiB 以下で NUL を含まない blob のみが対象です。パターンは網羅的ではなく、誤検知もあります。合格は「秘密情報がない」「安全に公開できる」という保証ではありません。JSON に含むパス自体にも個人情報があり得るため、結果をそのまま公開しないでください。競合とサブモジュールは明示的に失敗させます。

## テスト

```sh
python -m unittest discover -s tools/tests -p "test_repository_audit.py"
```

一時リポジトリを用いたインデックスと作業ツリーの差の検出、秘密値の非表示、サイズ境界、通常の素材メタデータの扱いを確認します。外部への通信は行いません。

## 構成と開発背景

- `tools/repository_audit.py`: パス分類、Git blob の読み取り、JSON 出力、CLI
- `tools/tests/test_repository_audit.py`: 標準ライブラリによる回帰テスト
- [EXTRACTION.md](EXTRACTION.md): 抽出元と独立化に伴う変更

AI 支援を利用して実装・抽出・検証しています。万能な秘密情報スキャナーではなく、公開準備時の補助チェックとして設計した小規模ツールです。依存ライブラリや他者の素材を一括して再ライセンスするものではありません。
